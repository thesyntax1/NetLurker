Your first investigation

Start with one question: which app is making this connection?

  1. Ctrl+F — find a process, such as proc:chrome.
  2. Select a connection and inspect its destination and available evidence.
  3. Enter — open the analysis. Without an AI key, local rules are available.

Just exploring? Ctrl+D opens a labeled synthetic demo. F1 shows shortcuts. Do not block or terminate a process based only on a score.

Useful context, not a verdict

A low score is not proof of safety. Missing provider data stays unavailable, not “clean”. Inspect the reasons, compare them with what the application is doing, and investigate before acting.

What it shows measurements and heuristics, with platform and provider limits

Try the explicitly labeled Windows demo with Ctrl+D. Synthetic examples are not live reputation findings. A risk score is an investigation priority, not a malware probability.

Identity & enrichment

Authenticode signatures, publisher, command line, owning module, geo/ASN, reverse DNS, RDAP ownership, TLS certificate details and banner-based version hints.

Risk engine 0–100

Review signals such as unusual ports, unsigned processes and connection patterns. Every signal needs context; a score is not a probability of malware.

Structured AI analyst

One keypress turns evidence into a structured verdict — decision, confidence, reasons, concerns, recommendation, follow-up actions. A separate local heuristic report is available without an API key.

Network graph

Process ↔ endpoint graph colored by risk, edge thickness by data flow, endpoints labeled with country codes.

Behavioral anomaly

Compares connection counts with local per-process baselines when enough observations are available. Changes are prompts to investigate, not confirmed incidents.

Plugin providers

Drop a JSON definition in plugins\ and feed your own intelligence source: IP on stdin, JSON verdict on stdout.

Privacy, by design the Privacy Center inside the app says the same thing

✓ Local processing

Local monitoring has no developer telemetry. Enrichment sends queried addresses to providers; optional AI sends investigation context.

✓ No telemetry

No analytics, no ads, no account.

✓ Explicit lookups

Several enrichment sources are enabled by default. Review Settings and the privacy policy before monitoring a sensitive network: ip-api.com, AbuseIPDB + DNS blacklists + CIRCL, rdap.org, VirusTotal (only with your key), TLS certificate probes and HTTP banner probes.

Speaks your language

English by default — UI, errors, risk reasons, column headers, tooltips, AI prompts, and reports use the selected language; raw provider errors may retain their original wording.

Release candidates

Candidate packaging produces a ZIP and a SHA256SUMS file so you can verify integrity before you run it. Hashes are not code signatures; candidates require review before publication.

Get started Windows desktop · x64 · portable ZIP or installer

Find Windows downloads Build from source

Choose -setup.exe for installation or extract the complete -win64.zip, including its lang/ folder. No account or AI key is required. If no package has been published yet, use the repository’s build instructions. “Source code” archives are not binaries.

How do I change the language?

Open Settings with Ctrl+S. The language picker is at the top. Choose a language and Save; the first launch is English. Türkçe and seven other interface languages are available.

Do I need to set up signing keys?

No. Signing is a maintainer setting, not an installation step. Check the release’s signature disclosure and SHA256SUMS.txt. Do not disable security protection to dismiss a warning.

What about Android?

The Android companion is available as source and development builds. It does not provide Windows-style live socket-to-app monitoring. Production APK publication is off by default; a debug or unsigned APK is never presented as a production release.

Something unclear or not working? Report a problem or suggest an improvement. Include your version and OS, but remove private addresses and credentials first.
